# ⚡ Vertical Video Maker | SocialLift Studio

Автоматизированный генератор вертикальных видеороликов (1080x1920) из набора изображений и аудиофайла. Идеально подходит для быстрого создания контента под форматы **Reels, Shorts, TikTok и Stories**.

---

## 🎯 Цель проекта

Предоставить digital-агентству **SocialLift Studio** и его клиентам простой, стабильный и масштабируемый инструмент для автоматической сборки промо-видео из статичных постеров и фоновой музыки. Основной упор сделан на простоту использования, скорость рендеринга и возможность работы как с десктопа, так и с мобильного устройства через веб-интерфейс.

---

## ✨ Возможности

- **Умная адаптация изображений** — горизонтальные и вертикальные фото автоматически вписываются в формат 9:16 без потери важных деталей (используется эффект размытого фона, как в Instagram/TikTok).
- **Гибкая работа с аудио** — автоматическое зацикливание или обрезка музыкального трека под общую длительность видеоряда.
- **Ускоренный рендеринг** — оптимизированные настройки кодирования (`ultrafast` preset, многопоточность) для максимальной скорости создания видео.
- **Современный веб-интерфейс** — адаптивный неоновый дизайн, удобный выбор файлов, визуальный прогресс-бар с обратным отсчётом времени до завершения генерации.
- **Полный контроль над видеорядом** — возможность добавлять, удалять и менять порядок изображений перед генерацией.
- **Безопасность** — корректная очистка временных файлов и освобождение ресурсов после генерации.
- **Кросс-платформенность** — работает на Windows, macOS и Linux.

---

## 🛠 Стек технологий

- **Язык**: Python 3.10+
- **Backend**: FastAPI, Uvicorn
- **Медиа-обработка**: MoviePy 2.x, Pillow (PIL), NumPy, imageio-ffmpeg
- **Frontend**: HTML5, CSS3 (Custom Properties), Vanilla JavaScript (Fetch API, XMLHttpRequest)
- **Упаковка**: PyInstaller (опционально, для создания .exe)

⚠️ Решение частых проблем
1. Антивирус блокирует создание видео (ошибка «Сеть» или «Программа-вымогатель»)
Некоторые антивирусы (например, 360 Total Security, Windows Defender, Kaspersky) могут ложно срабатывать на процесс записи видео через ffmpeg, воспринимая его как подозрительную активность.
Решение:
Откройте настройки вашего антивируса.
Найдите раздел «Белый список», «Исключения» или «Доверенные приложения».
Добавьте туда папку проекта: D:\путь\к\VerticalVideoMaker.
Перезапустите сервер и попробуйте снова.
2. Ошибка ffmpeg not found
Если MoviePy не может найти ffmpeg:
Убедитесь, что пакет imageio-ffmpeg установлен: pip install imageio-ffmpeg.
При первом запуске он скачивает ffmpeg автоматически — нужно интернет-соединение.
В крайнем случае, установите ffmpeg системно и задайте путь через переменную окружения:

🧩 Архитектура решения
Проект разделён на три независимых модуля:
main.py — ядро (движок). Отвечает за обработку изображений, склейку видео и экспорт. Не зависит от интерфейса и может использоваться как библиотека.
server.py — веб-слой на FastAPI. Принимает файлы из браузера, передаёт их в ядро и возвращает готовое видео.
gui.py — десктопный интерфейс на CustomTkinter. Альтернатива веб-версии для пользователей, предпочитающих классические приложения.
Такая архитектура позволяет легко масштабировать проект: например, добавить новые эффекты в main.py без изменений в интерфейсе, или заменить веб-фронтенд на React/Vue без переписывания логики.
